ContactOut is a B2B email finder and professional contact data platform (ContactOut Pty Ltd, founded 2015, San Francisco) that provides verified personal and work emails, phone numbers and enriched people and company profiles for 350M professionals across 40M companies, delivered through a Chrome extension, search portal, bulk tools, a REST API at api.contactout.com and a hosted MCP server at contactout.com/mcp. Used by recruiters and sales teams; GDPR and CCPA compliant with a published opt-out, and intended for professional B2B use only.

**Areas:** Company · Contact Data · Email Finder · Data Enrichment · People Search · Company Search · Email Verification · Sales Intelligence · Recruiting · B2B Data

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for ContactOut: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
